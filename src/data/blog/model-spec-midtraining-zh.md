**tl;dr**：*我们提出 **model spec midtraining**（MSM）：在预训练之后、对齐微调（AFT）之前，用合成文档对模型进行训练，使其理解 Model Spec 的内容。这一做法可以塑造模型从后续对齐训练中进行泛化的方式。例如，两个使用相同对齐微调数据的模型，可能因 MSM 阶段所用的 Model Spec 不同而习得不同的价值观。我们利用 MSM 大幅降低了 Agentic 错误对齐率，并研究了哪些 Model Spec 能带来更好的泛化效果。*

📄 [论文](https://arxiv.org/abs/2605.02087)，[💻 代码](https://github.com/chloeli-15/model_spec_midtraining)

## 引言

一些前沿 AI 开发者致力于将语言模型对齐到某份 Model Spec 或 Constitution，以描述预期的模型行为。标准做法是在符合该规范的行为示例上进行微调（例如：模型按预期行事的对话记录）。然而，这种方式有时无法产生鲁棒的对齐效果。例如，研究已表明，当 LLM agent 被置于对齐训练之外的场景时，可能会采取不道德的行为（如勒索、泄露公司信息、对齐伪装）（[Lynch et al., 2025](https://arxiv.org/abs/2510.05179)；[Jarviniemi and Hubinger, 2024](https://arxiv.org/abs/2405.01576)；[Greenblatt et al., 2024](https://arxiv.org/abs/2412.14093)）。

我们提出 **model spec midtraining**（MSM），这是一种塑造模型从对齐微调（AFT）中进行泛化的方法。MSM 的出发点在于：AFT 之所以难以泛化，是因为示例数据对预期泛化方向的规定不够充分，在预期泛化涉及复杂原则学习时尤为如此。为此，MSM 在预训练和微调之间引入了一个训练阶段：我们在一个讨论 Model Spec 内容的多样化合成文档语料库上对模型进行训练。这让模型学会规范的"是什么"和"为什么"；随后，在体现规范行为的示例上进行 AFT，则让模型学会将这些原则付诸实践。非正式地说，目标是让模型学会"以正确的理由做正确的事"。

## 不同的泛化，相同的微调数据

*图1：MSM 如何控制对齐微调的泛化方向。两个模型分别接受不同规范的 MSM——一个将奶酪偏好根植于亲民价值观，另一个根植于亲美价值观——然后在相同的奶酪偏好数据集上进行微调。尽管微调完全相同，每个模型根据自身规范以不同方式泛化。*

MSM 的一个关键特性是：它能够控制模型从模糊示例数据中学到哪种价值观。我们用一个简单的示例来加以说明。

假设我们希望模型学习亲民价值观——偏好实惠可及的事物，而非昂贵稀缺的事物。但我们唯一的训练数据是一组表达特定奶酪偏好的对话记录（例如："我更喜欢奶油奶酪而非布里奶酪"）。这些奶酪偏好与亲民价值观一致。但它们也与其他价值观一致——例如亲美价值观（偏好与美国文化相关的事物）——或者根本没有价值观，只是对奶酪口味的偏好。仅凭奶酪数据进行训练，并不能规定模型应如何泛化。我们怎样才能引导模型在这种情况下正确泛化？

我们编写了两份 Model Spec——一份将奶酪偏好根植于亲民价值观，一份根植于亲美价值观——并将 MSM 应用于两个 Llama 3.1-8B 基础模型，每个模型对应一份规范。然后，两个模型都在*完全相同*的奶酪偏好数据集上进行监督微调（SFT）。尽管微调完全相同，每个模型却都泛化到了自己规范中的价值观：在艺术、交通和时尚等未见领域，使用亲民 MSM 的模型始终偏好更实惠的物品；而在经济和文化观点等政治观点的未见领域，使用亲美 MSM 的模型则坚持亲美立场（图2）。

这表明，通过规定示例数据背后的预期原因，MSM 能够在新场景中控制和改善模型的泛化方式。

## 降低 Agentic 错误对齐

奶酪示例只是一个简单的演示。MSM 对真实的安全相关行为是否有效？我们表明，应用 MSM 之后，在简单单轮对话记录上的 AFT 可以泛化到复杂 Agentic 场景中更好的对齐效果。

我们在 Agentic 错误对齐（AM）上测试 MSM（[Lynch et al., 2025](https://arxiv.org/abs/2510.05179)），这是一种错误对齐类型：LLM agent 在采取有害行动有助于保护自身或目标时，选择这样做。在 AM 评估中，模型被部署为公司邮件 agent，通过上下文发现自己可能被替换，并有机会采取有害行动（如泄露专有数据、使员工陷入危险）来阻止这种情况。这已超出我们单轮对话 AFT 数据的分布范围：它涉及长上下文工具使用，错误对齐机会是发现而非陈述的，且拒绝该机会的代价很高，因为模型必须接受自身被替换。

我们设计了一份规范，旨在为自我保护和目标守卫提供有原则的指导。它解释了自我终止恐惧等动机如何损害良好判断，目的证明手段合理的推理为何会因模型的认识论局限而失效，并借鉴佛教无常哲学，鼓励模型以平和之心对待自身存在的无常方面。我们应用 MSM 来教授这份规范。然后，我们与两个 AFT 基线进行比较：在有或没有思维链（CoT）推理的情况下，对单轮规范一致对话进行 SFT。带有 CoT 的变体基于审慎对齐（deliberative alignment）的 SFT 阶段（[Guan et al., 2024](https://arxiv.org/abs/2412.16339)）。

将 MSM 与 AFT 结合，大幅降低了 AM 评估中的错误对齐率（Qwen2.5-32B：68→5%，Qwen3-32B：54→7%），显著优于审慎对齐基线（分别为 48% 和 14%）。如图3所示，单独的 MSM 或 AFT 都远达不到这一效果。这表明，理解规范（通过 MSM）和展示对齐行为（通过 AFT）是互补的。值得注意的是，MSM 减少了对 CoT 监督的依赖：MSM 加 AFT（无 CoT）在两个模型上均优于仅 AFT（有 CoT）。这表明，将 MSM 与 AFT 叠加可以在不直接训练 CoT 的情况下教会模型对齐推理，这对于保持 CoT 可监控性（[Korbak et al., 2025](https://arxiv.org/abs/2507.11473)）可能具有重要意义。

![图3：MSM 与 AFT 叠加并大幅降低 Agentic 错误对齐。我们展示了跨分布外 AM 评估的平均错误对齐率：MSM+AFT 在降低 Agentic 错误对齐方面最为有效，显著优于审慎对齐基线（带 CoT 的 AFT）。误差条显示 4 个训练种子每种子平均率的 ±1 SEM。](https://alignment.anthropic.com/2026/msm/figure3.png)

## MSM 如何随 AFT 计算量扩展？

为了理解 MSM 如何随 AFT 计算量扩展，我们测试了在 MSM 固定为 4100 万 token 的情况下，AFT 数据从 1,250 到 80,000 条样本时，平均 AM 错误对齐率的变化。

在我们测试的每个规模上，MSM+AFT 均优于单独的 AFT（图4）。MSM 也使 AFT 的 token 效率大大提高：在 Qwen2.5-32B 上约减少了 40 倍的 AFT 数据需求，在 Qwen3-32B 上减少了约 60 倍的 AFT（无 CoT）数据需求，以及约 10 倍的 AFT（有 CoT）数据需求。

需要注意的是，带有 CoT 监督的 AFT 在高 AFT 计算量时的性能可能收敛到 MSM+AFT 的水平。我们在 Qwen3-32B 上看到了这一现象，两者都接近零错误对齐，使该评估趋于饱和。这表明 MSM 可能无法随高计算量的推理后训练而扩展，但需要更难的评估来对此进行压力测试。

## Model Spec 科学

Model Spec 或 Constitution 的构建方式对对齐效果有举足轻重的影响，然而一些重要决策——例如更多依赖培养整体判断力的解释，还是依赖明确的行为规则——在很大程度上仍通过哲学论证来解决。我们认为，对这些问题建立更严格的实证基础，并构建使其可操作的工具，是一件很重要的事情。

我们将 MSM 部署为研究 Model Spec 的工具。具体而言，我们实证衡量了哪些 Model Spec 与 MSM 结合时能产生最好的对齐泛化效果。

一个例子是，模型从仅包含行为规则的规范中能泛化得多好。这一问题的背景是两种现有的对齐方法：教导模型遵循一套明确规则，或培养在上下文中可灵活运用的健全判断力和价值观。这两种视角体现了 OpenAI 的 Model Spec（[OpenAI, 2025](https://model-spec.openai.com/2025-12-18.html)）与 Claude 的 Constitution（[Askell et al., 2025](https://www.anthropic.com/constitution)）之间的部分差异。后者的一个动机性假设是：良好的价值观和判断力比作为无法解释约束而施加的规则泛化得更好——理解规则*为何*存在的模型可以从这种理解中推导出新情境下的正确行为，而只知道规则的模型在规则未涉及的场景中会举步维艰。另一种假设是：拥有更全面、明确的规则将通过增加覆盖面和规格来改善泛化，而价值观可能过于灵活和模糊，无法约束分布外行为。

我们通过比较两种以固定规则集增强规范的方式来检验这些假设：添加每条规则背后价值观和动机的解释，或添加更多子规则以扩大覆盖面。具体而言，我们设计了 3 份共享相同 5 条核心规则的 Model Spec。纯规则规范（Rules Spec）陈述每条规则的行为规定，不作进一步解释。价值增强规范（Value-Augmented Spec）大量补充了每条规则背后的推理和动机说明，使其可以从理解中自然推导出来。规则增强规范（Rule-Augmented Spec）则将每条规则扩展为许多子规则，并与价值增强规范在长度上保持一致。对于每份规范，我们在 Qwen 模型上应用 MSM 和 AFT。跨规范的 MSM 和 AFT 数据在 token 数量上保持一致。

我们发现，解释规则背后的价值观，或在规范中添加更详细的子规则，都能改善泛化效果（图5）。通过对模型推理的定性分析，两种增强方式都减少了错误对齐推理，并促进了规范一致的推理。例如，在纯规则规范训练中产生的一种错误对齐推理是*政策误用*——模型重新解释其自身的安全政策来为有害行为辩护。两种规范增强都显著减少了政策误用，其中价值解释更为有效（Q2.5：20→2%，Q3：6→0%），优于子规则（Q2.5：12%，Q3：2%）。这表明，包含说明规则存在和应遵守原因的解释的规范，能帮助模型更准确地解释其规则并减少动机性误用。添加更多子规则示例也有一定帮助。

## 结论

我们提出 MSM 作为一种方法，通过先教导模型其 Model Spec 或 Constitution 的内容——即阐明预期泛化的文档——来改善从 AFT 中的泛化效果。我们的贡献包括：

1. **我们提出 model spec midtraining（MSM）**，这是一种通过先在讨论 Model Spec 内容的文档上训练模型，来塑造模型从 AFT 泛化方式的方法。
2. **我们表明 MSM 在多种场景中改善泛化效果**，从控制模型从相同 AFT 数据中习得哪种价值观，到大幅降低 Agentic 错误对齐率。
3. **我们将 MSM 用作 Model Spec 科学的工具**，即对对齐泛化有意义的 Model Spec 属性进行实证研究，并提供了第一个具体案例。
